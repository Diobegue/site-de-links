# Site de links

Next.js (App Router) + Tailwind CSS, com tema claro/escuro, layout responsivo e fundo animado.

## Rodar

    npm install
    npm run dev

Abra http://localhost:3000

## Personalizar

Edite `lib/data.ts` (nome, bio, avatar, redes sociais e links).
Para usar uma foto, coloque o arquivo em `public/avatar.jpg` e defina `avatar: "/avatar.jpg"`.

## Deploy

Envie o projeto para o GitHub e importe na Vercel.
